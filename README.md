# budgie



LINK: https://budgie-s0nt.onrender.com/



A simple budget tracker personal project to continue my SQL and Python practice, and to learn a new framework - Flask.
This project also helped me collaborate with AI for front end UI/UX development.

## Features

- **Logs** — log expenses by category (Food, Rent, Transport, Entertainment, Groceries, Other), with support for all currencies (live conversion using exchangeRate API)
- **Savings system** - Keep track of monthly savings and/or losses.
- **Budget System** - Set budget for user.
- **Dashboard** — monthly spending, category breakdowns, high-spend days, and expense trends

## Tech stack (AI Assisted development for front end UI/UX)

- **Backend:** Flask (Python)
- **Database:** SQLite3
- **Templates:** Jinja2
- **Frontend:** vanilla HTML/CSS/JS (no framework)

## Getting started

Clone the repo:
```bash
git clone https://github.com/yourusername/budgie.git
cd budgie
```

Create and activate a virtual environment:
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

Install dependencies:
```bash
pip install -r requirements.txt
```

Run the app:
```bash
python app.py
```

Then open `http://localhost:5000` in your browser.

This is just a personal/portfolio project.
